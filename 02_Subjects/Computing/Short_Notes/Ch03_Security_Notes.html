🔑 Why is Computer Security Important?

Computer Security: The protection of computer systems and data from theft, damage, or unauthorised access. It ensures that data and programmes stored in a computer are safe.

Without security, your personal files, passwords, and data could be stolen or destroyed by others.

⚠️ Threats to Computer Security

🦠
Computer Virus
Malicious program that attaches itself to files and damages or deletes data
🐛
Worm
Self-replicating program that spreads through networks without user action
🐴
Trojan Horse
Disguised as a useful program but carries harmful code inside
🕵️
Spyware
Secretly collects user information without their knowledge
💣
Adware
Automatically shows unwanted advertisements
🔒
Ransomware
Locks your files and demands payment to unlock them

🛡️ How to Protect Your Computer

  • Use an Antivirus program — scans and removes viruses and malware. Keep it updated regularly.
  • Install a Firewall — monitors incoming and outgoing network traffic to block unauthorised access.
  • Use strong passwords — mix uppercase letters, lowercase letters, numbers, and symbols. Do not share passwords.
  • Keep software updated — updates often fix security vulnerabilities (weaknesses).
  • Make regular backups — save copies of important data on external drives or cloud storage.
  • Avoid unknown links and attachments — phishing emails try to trick you into revealing passwords.
💡 Strong Password Tips:
✅ At least 8 characters
✅ Mix of letters, numbers, symbols (e.g. Pass@123)
❌ Don't use your name or birthday
❌ Don't use the same password for everything

🔐 Username and Password Protection

Username: A unique name that identifies you on a computer or system.
Password: A secret code that prevents others from accessing your account.

When you log in to a computer or website, both your username and password are checked. This is called authentication.

❌ Never: Share your password with anyone (even friends!) | Write it where others can see | Use obvious passwords like "123456" or "password"

🛡️ Antivirus vs. Firewall

FeatureAntivirusFirewall
What it doesDetects and removes viruses/malware already on the computerBlocks unauthorised network access before it reaches the computer
Works onFiles and programs stored on the computerNetwork traffic (incoming and outgoing)
ExamplesAvast, Norton, KasperskyWindows Firewall, hardware firewalls
