🔑 What is Programme Development?

Programme (Program): A set of instructions written in a programming language that tells the computer what to do.
Programme Development: The process of planning, writing, testing, and fixing a computer programme.

📋 Steps in Programme Development

  1. Problem Identification — understand exactly what the programme needs to do
  2. Algorithm Development — plan the step-by-step solution
  3. Flowchart / Pseudocode — represent the algorithm visually or in plain language
  4. Coding — write the algorithm in a programming language
  5. Testing and Debugging — run the programme and fix errors (bugs)
  6. Documentation — write notes explaining how the programme works

📐 What is an Algorithm?

Algorithm: A step-by-step set of instructions to solve a problem. Must be: Clear, Finite (has an end), and Effective.
Example — Algorithm to make a cup of tea:
Step 1: Boil water
Step 2: Place teabag in cup
Step 3: Pour boiling water into cup
Step 4: Wait 2 minutes
Step 5: Remove teabag
Step 6: Add milk/sugar if desired
Step 7: Done!

📊 Flowcharts

Flowchart: A diagram that shows the steps of an algorithm using standard shapes connected by arrows.
ShapeNameMeaning
⬭ OvalTerminalStart or End of the programme
▭ RectangleProcessAn action or calculation (e.g. Add 5 to x)
◇ DiamondDecisionA Yes/No question (e.g. Is x > 10?)
▱ ParallelogramInput/OutputData entered by user OR result displayed
→ ArrowFlow LineShows the direction/order of steps
💡 Remember: Every flowchart MUST start and end with an Oval (Terminal). Decisions use a Diamond with YES and NO paths.

💬 Pseudocode

Pseudocode: A way of writing an algorithm in plain English (not a real programming language). It is easier to understand than actual code.
Example — Pseudocode to find if a number is even or odd:
START
INPUT number
IF number MOD 2 = 0 THEN
   PRINT "Even"
ELSE
   PRINT "Odd"
END IF
STOP

🐛 Errors (Bugs) in Programmes

Error TypeMeaningExample
Syntax ErrorSpelling or grammar mistake in codeWriting "pint" instead of "print"
Logic ErrorProgramme runs but gives wrong answerUsing + when you should use ×
Runtime ErrorProgramme crashes while runningDividing by zero
💡 Debugging: Finding and fixing errors in a programme. A programmer who fixes bugs is called a debugger.
