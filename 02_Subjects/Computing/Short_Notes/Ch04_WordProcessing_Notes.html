🔑 What is Word Processing?

Word Processing: Using computer software to create, edit, format, save, and print text documents. Microsoft Word (.docx) is the most common word processing software.

Word processing software is much better than a typewriter because you can correct mistakes, change fonts, add images, and format the document easily.

💻 The Microsoft Word Interface

  • Title Bar — shows the name of the document and the program
  • Ribbon / Toolbar — contains tools for formatting (Home, Insert, Page Layout, etc.)
  • Document Area — where you type your text
  • Status Bar — shows page number, word count, zoom level
  • Scroll Bar — used to move up and down the document

📄 Paragraph Formatting

  • Alignment: Left, Centre, Right, or Justified (Ctrl+L, Ctrl+E, Ctrl+R, Ctrl+J)
  • Line Spacing: Space between lines of text (single, 1.5, double)
  • Bullets & Numbering: Add bullet points or numbered lists to organise information
  • Indentation: Move text inward from the margin
💡 Remember: "Justify" makes both the left AND right edges of text perfectly straight — like in a newspaper.

📊 Tables in Word

Table: A grid of rows and columns used to organise data. In Microsoft Word, go to Insert → Table to create one.
  • A table has rows (horizontal) and columns (vertical)
  • Where a row and column meet is called a cell
  • You can merge cells, add borders, and shade rows in a table
