🔑 What is the CPU?

Central Processing Unit (CPU): A digital circuit that processes data according to given instructions. It is the brain of the computer — every task the computer performs goes through the CPU.

Think of the CPU like a chef in a hotel kitchen. Just as the chef prepares food from ingredients, the CPU takes in data and converts it into useful information. A dual-core processor is like having two chefs — two tasks can be done at the same time!

📍 Location: The CPU cannot be seen from the outside. It is fixed on the motherboard, inside the system unit.

⚙️ The Three Components of the CPU

🔢
Arithmetic & Logical Unit (ALU)
Performs all mathematical calculations (add, subtract, multiply, divide) and logical comparisons (greater than, less than, equal to)
🎮
Control Unit (CU)
Controls and coordinates all hardware connected to the computer. Manages input/output data — sends data to the right place at the right time
💾
Memory Registers
Temporarily stores data and instructions being used by the CPU. Very low storage capacity but extremely fast access speed
✅ Memory Tip: ALU = Calculations | CU = Control & Coordination | Registers = Temporary fast memory

⏱️ Speed of the CPU (Clock Speed)

Clock Speed: The number of instructions the CPU executes per second. Measured in Hertz (Hz).
UnitValue
Millisecond1 ms = 0.001 second
Microsecond1 μs = 0.000001 second
Nanosecond1 ns = 0.000000001 second
Picosecond1 ps = 0.000000000001 second
Kilohertz (KHz)1 KHz = 1,000 Hz
Megahertz (MHz)1 MHz = 1,000,000 Hz
Gigahertz (GHz)1 GHz = 1,000,000,000 Hz

Modern computers use MHz or GHz to measure CPU speed. MIPS = Millions of Instructions Per Second.
