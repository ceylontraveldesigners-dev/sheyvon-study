🔑 What is an Operating System?

Operating System (OS): A software that acts as a mediator between the user and the computer hardware. It is needed to use a computer for any task.

Tasks performed by the Operating System:

  • Provides a user interface to work easily with the computer
  • Controls activities related to storage devices
  • Manages files and folders correctly
  • Manages computer memory efficiently
  • Controls the functions of the CPU
  • Helps protect the computer through usernames and passwords
  • Manages hardware

💻 Types of Operating Systems

For computers:

  • Microsoft DOS (MS-DOS)
  • Microsoft Windows
  • Apple Macintosh (Mac OS)
  • Linux-based: Ubuntu, Fedora

For mobile phones:

  • Android — used in smartphones
  • iOS (iPhone OS) — used in Apple iPhone, iPad, iPod
  • BlackBerry OS — used in BlackBerry phones
  • Windows Mobile OS — used in Lumia, HTC

💾 Computer Storage Devices

Computer Storage Devices: Devices used to store data, information, and programmes that belong to a computer.

They can be divided into 3 types based on manufacturing technology:

🧲
1. Magnetic Media
Hard Disk, Floppy Disk, Magnetic Tape
💿
2. Optical Media
CD, DVD, Blu-ray Disk
🔌
3. Solid State Media
Pen Drive, SSD, Memory Card

🧲 Magnetic Media Devices

DeviceDetails
Hard DiskInternal hard disk (fixed inside system unit) and external hard disk (portable). Stores large amounts permanently. Sizes: 500 GB, 1 TB, 2 TB
Floppy DiskCapacity 1.44 MB — now obsolete. Zip disk (250 MB) and Jazz disk (2 GB) use similar technology
Magnetic TapeThin plastic tape with magnetic substance. Used to record sounds, images, data. Now obsolete

💿 Optical Media Devices

Data is read and written using laser beams. All are portable.

DeviceTypesCapacity
CD (Compact Disk)CD-R (write once), CD-RW (rewritable)650 MB – 700 MB
DVD (Digital Versatile Disk)DVD-R (write once), DVD-RW (rewritable)4.7 GB – 30 GB
Blu-ray DiskMulti-layer25 GB per layer

🔌 Solid State Media Devices

Solid State Devices: Store and retrieve data electronically at high speed. No moving parts like hard disks.
  • Pen Drive (USB Flash Drive) — portable, plug into USB port
  • SSD (Solid State Drive) — replaces hard disk, much faster
  • Memory Card — used in cameras and phones

📁 Files and Folders

File: Anything saved in a computer (letter, song, photo). Has two parts: File Name + File Extension.
Example: sportmeet.docx — name is "sportmeet", extension ".docx" shows it's a Word file.
Folder: A place where related files are stored together. Helps keep files organised and easy to find. Folders can have sub-folders inside them.
Common ExtensionsType
.docxWord processing (Microsoft Word)
.xlsxSpreadsheet (Microsoft Excel)
.pptxPresentation (PowerPoint)
.jpg / .pngImage files
.mp3Audio file
.mp4Video file
