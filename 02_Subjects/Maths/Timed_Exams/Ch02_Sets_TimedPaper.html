Section A — Multiple Choice (10 marks)

Q1. A = {vowels in 'MATHS'}. What is n(A)?

💡 Only 'A' is a vowel in MATHS. n(A) = 1.

Q2. Which is NOT a valid set?

💡 A set must use curly brackets.

Q3. If n(B) = 0, then B is:

💡 n(B) = 0 means no elements — empty set.

Q4. 5 ∈ {1,3,5,7} means:

💡 ∈ means 'is an element of'.

Q5. A = {2,4,6}, B = {1,2,3,4,5,6}. Is A ⊆ B?

💡 2,4,6 all appear in B, so A ⊆ B.

Q6. Which set equals {a,b,c}?

💡 Order doesn't matter: {c,b,a} = {a,b,c}.

Q7. n(∅) = ?

💡 The empty set has zero elements.

Q8. The set of odd numbers between 4 and 8 is:

💡 Odd numbers between 4 and 8: 5 and 7.

Q9. If every element of P is in Q, then:

💡 P is a subset of Q means P ⊆ Q.

Q10. Which is the correct notation for '6 is NOT in set A'?

💡 ∉ means 'is not an element of'.

Section B — True or False (3 marks)

Q11. The set {Monday, Tuesday, Wednesday} has n = 3.

💡 Three elements.

Q12. A set can contain repeated elements.

💡 Each element appears only once.

Q13. {1,2} ⊆ {1,2,3,4}

💡 Both 1 and 2 are in the larger set.

Section C — Fill in the Blank (2 marks)

Q14. The set of factors of 6 is {1, 2, 3, ___}.

💡 Factors of 6: 1, 2, 3, 6.

Q15. If A = {p, q, r}, then n(A) = ___.

💡 Three elements.
