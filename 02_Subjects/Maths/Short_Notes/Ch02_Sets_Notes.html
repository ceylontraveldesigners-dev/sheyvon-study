🔑 Key Concepts — Sets

Set: A well-defined collection of distinct objects. Sets are written using curly brackets: {1, 2, 3}
Element / Member: Each object in a set. We write 3 ∈ {1, 2, 3} to say '3 is an element of the set'.
Empty Set: A set with no elements. Written as {} or ∅. Example: {whole numbers between 5 and 6} = ∅
Cardinality: The number of elements in a set. If A = {a, b, c}, then n(A) = 3.
Subset: Set A is a subset of Set B if every element of A is also in B. Written A ⊆ B.

📌 Rules to Remember

✅ Rule 1: The order of elements does NOT matter. {1,2,3} = {3,1,2}.
✅ Rule 2: Each element is listed only once. {1,1,2} should be written as {1,2}.
❌ Common Mistake: Don't confuse n(A) (number of elements) with the set itself. n({4,5,6}) = 3, NOT {4,5,6}.

✏️ Worked Examples

Example 1: List the set of even numbers between 1 and 10.

→ A = {2, 4, 6, 8, 10}. There are 5 elements, so n(A) = 5.
Example 2: Is 7 an element of B = {2, 4, 6, 8}?

→ No. We write 7 ∉ B.
Example 3: Is {2, 4} a subset of {1, 2, 3, 4, 5}?

→ Yes, because both 2 and 4 are in the larger set.
