🔑 Key Concepts — Data

Data Collection: Gathering information (data) through surveys, counts, or observations.
Frequency Table: A table showing how many times each value occurs. Uses tally marks.
Mean: Average. Mean = Sum of all values ÷ number of values.
Mode: The most frequently occurring value in a data set.
Median: The middle value when data is arranged in order. If even count: average of two middle values.
Range: Largest value − Smallest value.

📌 Rules to Remember

✅ Rule 1: To find median: first arrange data in ORDER, then find the middle.
✅ Rule 2: Mean = Sum ÷ Count. Mode = most frequent. Median = middle value.
❌ Common Mistake: Don't find the median without sorting the data first!

✏️ Worked Examples

Example 1: Data: 5, 3, 8, 5, 6. Find mean, mode, median.

→ Mean=(5+3+8+5+6)÷5=27÷5=5.4. Mode=5 (twice). Sorted:3,5,5,6,8 → Median=5.
Example 2: Data: 2,4,6,8. Median?

→ Even count. Middle two: 4 and 6. Median=(4+6)÷2=5.
Example 3: Range of 3,7,2,9,5?

→ Max−Min=9−2=7.
