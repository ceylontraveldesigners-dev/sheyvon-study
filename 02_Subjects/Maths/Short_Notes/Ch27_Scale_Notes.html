🔑 Key Concepts — Scale Drawings

Scale: A ratio comparing measurements on a drawing to real measurements. Written as 1:n.
Scale Drawing: A drawing that represents a real object, reduced or enlarged by a fixed ratio.
Reading a Scale: If scale is 1:100, then 1 cm on drawing = 100 cm in real life.
Finding Real Length: Real = map length × scale denominator.
Finding Map Length: Map = real length ÷ scale denominator.

📌 Rules to Remember

✅ Rule 1: Scale 1:n means 1 unit on map = n units in reality.
✅ Rule 2: Always use the SAME units on both sides of the scale.
❌ Common Mistake: Don't forget to convert units. 1:50000 means 1cm on map = 50000cm = 500m = 0.5km in reality.

✏️ Worked Examples

Example 1: Scale 1:200. Map length = 5cm. Real length?

→ 5 × 200 = 1000 cm = 10 m
Example 2: Real length = 15 m. Scale 1:500. Map length?

→ 1500 cm ÷ 500 = 3 cm
Example 3: A map of scale 1:50000. 4cm on map = how many km?

→ 4 × 50000 = 200000 cm = 2000 m = 2 km
