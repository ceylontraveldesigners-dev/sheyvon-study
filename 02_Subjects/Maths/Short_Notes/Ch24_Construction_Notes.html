🔑 Key Concepts — Construction

Geometric Construction: Drawing shapes accurately using a ruler and compass (no measuring angles).
Perpendicular Bisector: A line that cuts another line in half at 90°. Constructed with a compass by drawing arcs from each end.
Angle Bisector: A line that divides an angle into two equal parts. Constructed using a compass.
Constructing a Triangle: Draw base, then use compass set to each other side length to find the third vertex.
Locus: The set of all points satisfying a given condition. e.g. equidistant from two points → perpendicular bisector.

📌 Rules to Remember

✅ Rule 1: Construction uses ONLY compass and ruler (straightedge). No protractor for basic constructions.
✅ Rule 2: Perpendicular bisector: open compass more than half the line, draw arcs above and below from both ends.
❌ Common Mistake: Don't change the compass width while drawing arcs for the same construction step.

✏️ Worked Examples

Example 1: Perpendicular bisector of line AB

→ Set compass to more than half AB. Draw arcs from A and B. Join intersection points.
Example 2: Bisect angle ABC

→ Place compass at B, mark equal arcs on BA and BC. From these points, draw crossing arcs. Join B to intersection.
Example 3: Construct equilateral triangle, side 5cm

→ Draw base 5cm. Set compass to 5cm, draw arc from each end. Where arcs cross = third vertex.
