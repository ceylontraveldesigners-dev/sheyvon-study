🔑 Key Concepts — Indices

Index / Exponent: The small raised number showing how many times the base is multiplied by itself. In 2⁴, the base is 2 and the index is 4.
Base: The number being multiplied. In 3⁵, the base is 3.
Standard Form: 2⁴ = 2 × 2 × 2 × 2 = 16. Read as 'two to the power of four'.
Zero Index: Any number to the power of zero equals 1. a⁰ = 1 (a ≠ 0).
Index 1: Any number to the power of one equals itself. a¹ = a.
Multiplication Law: When multiplying same base: aᵐ × aⁿ = aᵐ⁺ⁿ.
Division Law: When dividing same base: aᵐ ÷ aⁿ = aᵐ⁻ⁿ.

📌 Rules to Remember

✅ Rule 1: The laws of indices only apply when the BASE is the same.
✅ Rule 2: a⁰ = 1 for any non-zero a. This is always true!
❌ Common Mistake: 2³ ≠ 2 × 3 = 6. It means 2 × 2 × 2 = 8.

✏️ Worked Examples

Example 1: Calculate 3⁴

→ 3 × 3 × 3 × 3 = 81
Example 2: Simplify 2³ × 2⁵

→ Same base: 2³⁺⁵ = 2⁸ = 256
Example 3: Simplify 5⁶ ÷ 5²

→ Same base: 5⁶⁻² = 5⁴ = 625
