🔑 Key Concepts — Algebra

Variable: A letter used to represent an unknown number. e.g. x, y, a, b.
Expression: A combination of numbers, variables, and operations. e.g. 3x + 2. No equals sign.
Term: Each part of an expression separated by + or −. In 4x + 3y − 2, there are 3 terms.
Like Terms: Terms with exactly the same variable(s). 3x and 5x are like terms; 3x and 3y are NOT.
Coefficient: The number in front of a variable. In 7x, the coefficient is 7.
Substitution: Replacing variables with given numbers to find the value of an expression.

📌 Rules to Remember

✅ Rule 1: Only LIKE terms can be added or subtracted. 3x + 4x = 7x, but 3x + 4y cannot be simplified.
✅ Rule 2: Multiplying terms: multiply coefficients and combine variables. 3x × 4y = 12xy.
❌ Common Mistake: 3x + 4x ≠ 7x². The variable stays the same: 3x + 4x = 7x.

✏️ Worked Examples

Example 1: Simplify 5x + 3y + 2x − y

→ Collect like terms: (5x+2x) + (3y−y) = 7x + 2y
Example 2: If x = 3, find 4x − 1

→ 4(3) − 1 = 12 − 1 = 11
Example 3: Expand 3(2x + 5)

→ 3×2x + 3×5 = 6x + 15
