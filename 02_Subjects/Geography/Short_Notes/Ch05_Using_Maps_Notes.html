🗺️ Using Maps

Map Skills – Direction, Scale, Key & Index

📖 Key Concepts

Map — A scaled, flat representation of an area showing physical and human features.
Direction — North is at the top of a map unless stated otherwise. North, South, East, West are cardinal directions.
Scale — The ratio between distances on the map and actual distances on the ground. Shown as a line scale, ratio, or statement.
Key (Legend) — A list of symbols and colours used on the map and what they represent.
Map Index — An alphabetical list of place names with grid references to help find locations on a map.
Atlas — A book of maps. Sri Lanka Atlas (Sithiyam Sangrahaya) is published by the Survey Department.
Relief Map — Shows the height of land using contour lines or colour shading.
Topographic Map — Detailed map showing both natural and human features (roads, buildings, rivers, hills).

📌 Important Rules & Facts

📌 If no direction arrow is shown on a map, North is assumed to be at the top.
📌 A map must always have: title, direction, scale, key (legend).
📌 Scale = Map distance ÷ Actual distance. A larger scale shows more detail but less area.
📌 The map index uses alphabetical order — useful for finding towns and rivers quickly.

💡 Examples

Scale example: If the scale is 1:50,000, then 1 cm on the map = 50,000 cm (500 m) on the ground.
Using a key: A blue line on a map represents a river; a black dotted line may represent a footpath.
Using the index: To find 'Kandy' in the atlas: look under 'K' in the index and use the grid reference to find it on the map.

🔑 Chapter Summary

Maps represent real areas at a reduced scale. Key map skills include reading direction (North = top), understanding scale (map distance vs real distance), using the key (legend) to interpret symbols, and using the index to find places alphabetically.

🌟 Bonus Questions

Q: List four essential features every map must have.
A: Title, direction indicator (north arrow), scale, and key (legend).
Q: Explain the difference between a relief map and a topographic map.
A: A relief map shows the height of land using contour lines or colour shading. A topographic map shows both physical features (rivers, hills) and human features (roads, buildings) in detail.
